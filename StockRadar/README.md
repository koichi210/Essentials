# 株レーダー（StockRadar）

日本株の買い候補と、買ったあとに売る値段（利確・損切り）の目安を、ボタンを押した時点のデータで一覧にするローカル専用ツールです。空売りの候補は出しません。

- 期間（**短期** 1〜2週間／**長期** 半年〜1年）と、100株を買うのに使える予算（上限・下限）を入れて「買い候補を探す」を押す
- 銘柄ごとに **買いスコア**（買い候補としての点数）と、**買い（指値の幅）・利確・損切り** の値段と、100株での損益の目安、短期なら手じまいの期限を出す
- **絞り込み**（すべて満たす銘柄だけ）: PER（◯倍以下）・PBR（◯倍未満）・ゴールデンクロス／デッドクロス（N日以内に起きた・もうすぐ起きそう。デッドクロスは「起きた銘柄を除く」も選べる）。クロスを見る線は「5日線と25日線」「25日線と75日線」「MACD」から選ぶ
- 現在値の横に **前日終値** と前日比（上がったら赤・下がったら青）を出す。短期は日足の1本前の終値、長期は Yahoo の `regularMarketPreviousClose`
- 銘柄ごとに **チャート**（日足100本・週足78本のローソク足、移動平均線、クロスの印、買いの範囲・利確・損切りの線）を押しポイントの右に出す（幅1000px未満では下）。画面に近づいたカードから読み込む。なぞるとその日の値段と前日比が出る。ローソク足の色は前の足の終値より上がったら赤・下がったら青、中抜きは始値より上で終わった足・塗りつぶしは下で終わった足
- **スナップショット**: 調べた結果を「📸 この結果を保存」で保存し、右上の「📸 スナップショット」から開く。開くと、保存した銘柄ごとに今の値段・変化・その後の高値と安値・利確と損切りのどちらに先に届いたかを表で出す。最新の検索結果があれば、今の順位と新しく入った銘柄も出す
- 表示した銘柄の **並べ替え**: 買いスコア・最低購入金額・PBR・PER（安い順／高い順）。値の無い銘柄は最後。選んだ並び順はブラウザに覚えておく
- 日経平均の地合い（25日線・75日線との位置）も一緒に出す
- 銘柄ごとに **押しポイント・気をつけるところ** を「PBR 0.72倍 … 会社の持ち物(純資産)より約3割安い値段」のような文で出す
- 下線の付いた言葉(PER・PBR・ROE・RSI・押し目・損切り など)を押すと **用語集** が開き、意味と目安(何倍なら割安か など)が出る。判断を入れない **基準**（東証プライムの平均や、PBR 1倍のような定義上の境目）も載せ、銘柄カードの数字の横にも「(境目1倍・平均約1.7倍)」のように出す。平均は JPX の集計などから取った値なので、ときどき `public/glossary.js` の `base` を新しい値に直す。右上の「用語集」ボタンからも開ける
- 銘柄ごとに **配当**（100株での年額・権利確定月）と **株主優待**（種類・内容・権利付き最終日・100株で対象か・継続保有の条件）を出す。短期で持つ間に権利確定日が来るときは知らせる

データは Yahoo! Finance の公開データ（スクリーナー・日足・週足・配当履歴。約20分遅れ）と、Yahoo!ファイナンス（日本）の優待ページ（`/quote/XXXX.T/incentive`）です。優待ページは HTML から読み取っているので、ページの作りが変わると「取得できませんでした」になります。配当・優待は画面に出す上位20銘柄の分だけ取り、12時間覚えておきます。日足・週足は10分覚えておきます。決まったルールで機械的に判定しているだけで、決算の中身やニュースは読んでいません。値上がりを保証するものではありません。

## 動かし方

Node.js 20 以上。npm パッケージは使いません。

```
start.bat        起動済みならブラウザで開くだけ、未起動なら起動
stop.bat         8766 で LISTEN 中のプロセスを止める
autostart.ps1    窓なしで裏起動（SecretaryGadget の「株レーダー」メニューから呼ばれる）
remote-setup.ps1 スマホから開けるようにする（下の「スマホから開く」）
```

待ち受けは `http://127.0.0.1:8766/` だけです（他の PC からは直接つながりません）。テストは `node --test test/analyze.test.js`。

## スマホから開く（Tailscale）

自分の Tailscale（VPN）につないだ端末だけが開けるようにします。インターネットには公開しません（Funnel は使いません）。

1. PC とスマホに [Tailscale](https://tailscale.com/download) を入れて、同じアカウントでログインする
2. Tailscale の管理画面（DNS）で MagicDNS と HTTPS Certificates を有効にする
3. PC で `powershell -ExecutionPolicy Bypass -File remote-setup.ps1` を実行する
4. スマホで Tailscale をオンにして、表示された `https://<PC の名前>.<tailnet>.ts.net/` を開く

`remote-setup.ps1` は、PC の Tailscale の名前を `%LOCALAPPDATA%\StockRadar\config.json` の `allowedHosts` に書き、ログオン時にサーバーを起動するタスク「StockRadar」を登録し、`tailscale serve` で `127.0.0.1:8766` へ中継します。サーバーの待ち受けは `127.0.0.1` のままです。やめるときは `-Remove` を付けて実行します。PC がスリープ中や電源オフのときは開けません。

受け付ける名前は `config.json` の `allowedHosts` か、環境変数 `STOCK_RADAR_HOSTS`（カンマ区切り）で足せます。名前はリポジトリに書かず、PC の中だけに置きます。

## 判定のルール

対象は、100株の金額が予算に収まり、時価総額500億円以上の東証の銘柄です。

### 短期（analyzeShort）

日足から 25日線・75日線・RSI(14)・ATR(14)・出来高を計算し、次の3つの形を探します。

| 形 | 条件 |
|---|---|
| 押し目 | 上昇トレンド（終値と25日線が75日線より上）の中で、25日線の −3%〜+2% まで下げてきて RSI 38〜55 |
| 高値ブレイク | 20日高値を更新し、5日平均の出来高が25日平均の1.5倍以上、RSI 75 未満 |
| 決算後の初動 | 7日以内の決算で、発表前の終値より3%以上高く、反応した日の始値近くを保っている |

- 除外: 7日以内に決算発表がある（大負けしやすいため）／1日の売買代金が3億円未満
- 加点: 上昇トレンド、25日線が上向き、出来高の増加、MACD のゴールデンクロス(3日以内)、ROE 10%以上
- 減点: RSI 70 以上の過熱、25日線から8%以上の上ぶれ、下降トレンド、決算発表済みでまだ反応していない、赤字
- 買い: 押し目は25日線のすぐ下まで、それ以外は今の値から ATR の半分下まで
- 損切り: 買いから ATR の1.5倍下（ただし7%より深くしない）
- 利確: 損切り幅の2倍上。途中に60日高値・52週高値があればその手前
- 期限: 10営業日（祝日は数えていません）

### 長期（analyzeLong）

PER（予想があれば予想）・PBR・ROE・配当利回り・配当性向・利益の伸び・アナリスト評価・200日線との位置で点を付けます。赤字の銘柄は除外し、200日線を15%以上割っている銘柄は「割安の罠」として減点します。

| 指標 | 加点・減点 |
|---|---|
| PER | 10倍以下 +25、15倍以下 +18、20倍以下 +8、40倍超え −10 |
| PBR | 0.8倍未満 +20、1倍未満 +15、1.5倍未満 +8 |
| ROE(1株利益 ÷ 1株純資産) | 15%以上 +12、10%以上 +8、8%以上 +4、5%未満 −5 |
| 配当利回り | 4%以上 +20、3%以上 +15、2%以上 +8 |
| 配当性向(1株配当 ÷ 1株利益、利回り2%以上のとき) | 50%以下 +5、100%超え −10 |
| 増益予想(来期の1株利益が1割以上増える) | +5 |
| アナリスト評価(Yahoo の平均。1が最高・5が最低) | 2.0以下 +8、2.5以下 +4、3.5以上 −5 |
| 200日線 | 上 +15、15%以上下 −15 |
| 52週高値の3%以内 | −5 |

- 買い: 50日線より上なら50日線まで（5%下まで）、下なら3%下まで
- 損切り: 10%下／利確: 20%上（52週高値が手前にあればその手前）

### 絞り込み（matchValuation / crossInfo / matchCross）

- PER・PBR はスクリーナーの値で、日足を取る前に絞る。指定したときは値の無い銘柄（赤字など）を外す
- クロス: 短い線 − 長い線 の差が、マイナスからプラスになった日がゴールデンクロス、逆がデッドクロス（直近20本を見て、いちばん新しい交差だけ使う）。「N日以内」は今日の足を1日目に数える
- もうすぐ起きそう: 差がこの3日と同じ速さで縮むと、3日以内に0になるとき
- 短期でデッドクロスを指定したときは、50日線での事前の絞り込みをしない（下げている銘柄が対象のため）。「除く」のときは絞り込む
- 除く（`dc=not10` など）: N日以内に起きた（「もうすぐ」も含めるならそれも）銘柄を外す。日足を取れなかった銘柄も外す
- 長期は日足を使わない判定なので、クロスを指定したときは点の高い150銘柄だけ日足を取って確かめる

### 配当・優待（parseDividends / parseIncentive）

- 配当の権利確定月: 過去2年の配当の権利落ち日の月（権利確定日と同じ月）
- 優待の権利確定月: 優待ページの「権利付き最終日」の月
- 継続保有の条件: 優待の内容のうち「継続」を含む行をそのまま出し、いちばん短い期間（「1年以上」「6か月以上」など）を見出しにする
- 短期で持つ間（今日〜期限）に、優待の権利付き最終日か、配当の確定月の月末が入るときは「保有中に権利確定」と出す（権利落ち日は株価が下がりやすいため）

### スナップショット（compareSince）

- 保存した銘柄ごとに、保存したときの株価の日付より後の日足を見る。高値が利確以上、または安値が損切り以下になった最初の日を「届いた日」とする
- 同じ日に両方届いたときは、1日の中の順番が分からないので「同じ日に両方」とする
- 値段の変化は、保存したときの株価から今の終値まで（買いの指値で買えたかどうかは見ていない）

### 用語集（public/glossary.js）

押しポイントの `term` と画面のリンクが、用語集の `id` を指します。しきい値を変えたら、用語集の目安(`scale`)も合わせてください。

## 書き込むファイル

サーバが書くのはスナップショットだけで、`%LOCALAPPDATA%\StockRadar\snapshots\<保存した時刻>.json` に1つずつ保存します。`autostart.ps1` で起動したときは、ログを `%LOCALAPPDATA%\StockRadar\server.log` に書きます（どちらも環境変数 `STOCK_RADAR_DATA` で場所を変えられます）。入力した予算・前回の結果・並び順は、ブラウザの localStorage に保存します。

スナップショットの保存と削除は、この画面から送られたもの（Origin が `127.0.0.1:8766`・`localhost:8766`・`allowedHosts` の名前のどれか）だけ受け付けます。
