# BlurPaint

スクリーンショットに矢印・枠・文字・番号・蛍光ペン・**ぼかし／モザイク**の注釈を入れる、ブラウザだけで動く軽量のペイントエディタです。
HTML + CSS + JavaScript だけで動き、インストール・ビルド・外部通信は一切ありません。

`Win + Shift + S` で撮った画像を `Ctrl + V` で貼り、注釈を入れて `Ctrl + C`（コピー）か `Ctrl + S`（保存）で出すのが基本の流れです。

## 起動

- `BlurPaint.bat` をダブルクリック（Edge のアプリ窓＝タブ・アドレスバー無しで開きます）
- または `index.html` をブラウザで直接開く（最新の Edge / Chrome）

## ツール

| キー | ツール | 操作 |
|---|---|---|
| V | 選択・移動 | クリックで選択、ドラッグで移動、ハンドルで変形、ダブルクリックでテキスト再編集 |
| A | 矢印 | ドラッグ（Shift で 45° 単位） |
| R / E | 矩形 / 楕円 | ドラッグ（Shift で正方形 / 正円） |
| L | 直線 | ドラッグ（Shift で 45° 単位） |
| P | フリーハンド | ドラッグ |
| T | テキスト | クリックで入力。Enter 確定 / Shift+Enter 改行 / Esc 取消 |
| N | 番号 | クリックで ①②③… を順に配置 |
| H | 蛍光ペン | ドラッグした範囲を塗る（乗算） |
| B | ぼかし・モザイク | ドラッグした範囲をぼかす。方式と強さ（2〜40）は後から変えられる |
| C | トリミング | ドラッグで残す範囲 → Enter で実行 / Esc で解除 |

## ショートカット

| キー | 動作 | キー | 動作 |
|---|---|---|---|
| Ctrl+Z | 元に戻す | Ctrl+D | 選択を複製 |
| Ctrl+Y / Ctrl+Shift+Z | やり直し | Ctrl+0 / Ctrl+1 | 全体表示 / 等倍 |
| Ctrl+C | PNG でコピー | Ctrl++ / Ctrl+- | 拡大 / 縮小 |
| Ctrl+S / Ctrl+O | 保存 / 開く | Ctrl+ホイール | カーソル位置を中心に拡大縮小 |
| Ctrl+V | 画像を貼り付け | Delete | 選択を削除 |
| Enter | トリミング実行 / テキスト再編集 | 矢印キー | 選択を 1px（Shift で 10px）移動 |
| Esc | トリミング範囲の解除 → 選択解除 → 選択ツールへ | | |

## 機密情報を隠すときは

**ぼかし**は強さが弱いと文字が読めてしまうことがあります。パスワードや個人情報など、確実に隠したいものは**モザイク**（強さを大きめ）か、塗りつぶしを使ってください。

## 保存されるもの

画像データはブラウザの外へ出しません。`localStorage`（キー `blur-paint.settings`）には、ツール・色・太さなどの**設定値だけ**を保存します。
