# MagicLauncher

よく開く Web ページ・フォルダ・ファイルを、ブラウザの中の**光る魔法陣**の上に円として並べ、クリックで Windows の既定のアプリで開く個人用ランチャーです。

- 中心の結晶から**タグ = 分岐点**へ回路のような線が伸び、その先に**登録した項目 = 小さな魔法陣**がぶら下がります
- タグに魔法陣の名前を付けると、魔法陣が分かれて横に並びます（横に並べる数は設定で 1〜4 / 横一列）
- ブラウザだけではローカルのフォルダを開けないので、**127.0.0.1 だけで待ち受ける小さな Node サーバ**が「設定ファイルの読み書き」と「開く」を受け持ちます
- 登録データは 1 つの JSON（`launcher.json`）。OneDrive などに置けば複数の PC で共有できます（`%USERPROFILE%` などの環境変数が使えます）

## 動かし方

Windows 10/11、Node.js 18 以上。npm パッケージは使いません（three.js r128 は `public/vendor/` に同梱、オフラインで動きます）。

```
start.bat        起動していなければ裏で起動して、既定のブラウザで http://127.0.0.1:8790/ を開く
stop.bat         8790 で待ち受けているプロセスだけを止める（ほかの node は止めない）
autostart.ps1    窓なしで裏起動（Node が無ければ確認してから winget で入れる）
open.ps1         窓なしで、起動していなければ起動してからブラウザで開く（秘書さんの吹き出しの選択肢などから呼ぶ用。開けなければ理由を1行出して終了コード 1）
```

PC の起動時に立ち上げるには、次のショートカットを `shell:startup` に置きます。

```
powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "<このフォルダ>\autostart.ps1"
```

ポート番号は `server.js`・`start.bat`・`stop.bat`・`autostart.ps1`・`open.ps1` の 5 か所に出てきます（変えるときは全部）。

## ファイル

| ファイル | 役割 |
|---|---|
| `server.js` | サーバ（標準モジュールのみ）。public/ を配る・設定ファイルの読み書き・登録済み id を開く |
| `opener.cs` | 「開く係」。サーバ起動時に .NET Framework 付属の `csc.exe` でビルドし、`%LOCALAPPDATA%\MagicLauncher\opener.exe` に置く（opener.cs の方が新しいときだけ作り直す） |
| `public/` | 画面。`index.html`・`launcher.css`・`launcher.js`（画面・操作・検索）・`magic.js`（魔法陣の描画部品）・`vendor/`（three.js r128 一式） |
| `test/server.test.js` | サーバのテスト（`node --test test/server.test.js`。本番ポートを使わず 8791 で別に立てる） |

PC ごとのファイルは `%LOCALAPPDATA%\MagicLauncher\` に置きます: `settings.json`（設定ファイルの場所）・`server.log`（1MB を超えたら作り直す）・`opener.exe`。

### 開く係（opener.exe）が要る理由

サーバは窓を持たない裏方のプロセスなので、そこから直接開くと Windows のフォアグラウンド制限で、開いたエクスプローラーがブラウザの後ろに隠れます。小さな WinForms の exe がいったん見えない手前の窓になってから開くことで、開いた窓を手前に出します。ビルドできない PC では `rundll32 url.dll,FileProtocolHandler` に切り替えます（開けますが窓は後ろに出ます。理由は server.log に残ります）。

## 設定ファイル（launcher.json）

```json
{
  "version": 1,
  "title": "Launcher",
  "idle": "float",
  "columns": 0,
  "circles": ["共通", "製品"],
  "circleColors": { "製品": "#19b6d2" },
  "tags": {
    "リポジトリ": { "color": "#ff5fd2", "circle": "共通" }
  },
  "items": [
    { "id": "i1a2b3c4d", "name": "SeedEditor", "path": "%USERPROFILE%\\Work\\SeedEditor",
      "tags": ["リポジトリ", "レジプラ"], "emoji": "", "note": "" }
  ]
}
```

- `items` の必須は `path` だけ（手で書き足せます）。`id` が無い項目には「中身と位置から決まる id」を読むたびに同じ値で付けます
- `path` は `%VAR%` を展開してから使います。`https://` のほか `onenote:`・`vscode://` のようなスキーム付き URL も可（「英字 + :」で 2 文字以上を URL 扱い。`C:` はパス）
- `tags` のキーの順が魔法陣でタグが並ぶ順。新しいタグには 12 色のパレットから未使用の色を順に割り当てて書き込みます
- 項目の**先頭のタグ**が円の色と置き場所を決めます。2 つ目以降のタグの分岐点からは、選んだときだけ光る線が伸びます
- どの項目にも使われていないタグは画面に出しません。`name` が空なら、URL はホスト名、パスは末尾の名前を表示名にします
- `idle`（待機中の動き）は `orbit`（既定。ファイルには書かない）/ `float` / `off`。`columns` は 0〜12（0 = 横一列）

### 読み書きのルール（壊さない・他 PC の変更を消さない）

- 書き込みのたびに**ディスクの内容を読み直してから差分だけ当てて**保存します（画面が持つ古い一覧で上書きしない）。保存直前に `.bak` へ 1 世代コピー
- 読めない・一番外が `{}` でない・`items` が配列でない・フォルダを指定 → 画面に赤い帯で警告し、書き込みは 409 で拒否（空の内容で上書きしない）
- 版数 = `mtime(ms)-size`。画面は 10 秒ごと（とタブに戻ったとき）`/api/version` を見て、変わっていたら読み直します
- 種類の判定はネットワークパスで固まらないよう 1.5 秒で打ち切り（`unknown`）、結果は 30 秒キャッシュ。開くときの確認は 5 秒まで

## API（すべて JSON。POST は本文 1MB まで、ヘッダ `X-Launcher: 1` が必須）

| メソッド・パス | 受け取るもの | 動き |
|---|---|---|
| `GET /api/state` | — | 画面に必要な全部（`configPath`・`tags`・`items[{id,name,path,tags,emoji,note,kind}]` など） |
| `GET /api/version` | — | `{version, configPath}`（変更チェック用） |
| `POST /api/item` | `{item:{id?,name,path,tags[],emoji,note}}` | id があれば更新（無ければ 404「ほかの PC で削除されたかも」）、無ければ追加して `{id}` |
| `POST /api/item/delete` | `{id}` | 削除 |
| `POST /api/tag` | `{name, color?, circle?}` | タグの色・置く魔法陣 |
| `POST /api/tags/swap` | `{a, b}` | タグの並びを交換（別の魔法陣どうしなら circle も交換） |
| `POST /api/items/swap` | `{a, b}`（id） | 項目の並びを交換（同じ先頭タグどうしのみ） |
| `POST /api/circles` | `{order:[名前…]}` | 魔法陣の左右の並び |
| `POST /api/circle` | `{name, color}` | 魔法陣の色（空で自動に戻す） |
| `POST /api/layout` | `{columns?, idle?}` | 横に並べる数・待機中の動き |
| `POST /api/config` | `{path}`（空で既定へ） | 設定ファイルの場所を settings.json に保存（フォルダは拒否） |
| `POST /api/open` | `{id}` | **登録済みの id だけ**開く。`%VAR%` 展開 → 存在確認（無い = 404・応答なし = 504）→ 開く係。`{opened, dryRun}` |

### 安全のための作り

- `127.0.0.1` にだけ bind（ほかの PC からはつながらない）
- `Host` が `127.0.0.1:8790` / `localhost:8790` 以外は拒否（DNS リバインディング対策）
- GET/HEAD 以外は、`Origin` が付いていれば自分自身のみ、かつ独自ヘッダ `X-Launcher: 1` 必須（よそのページはプリフライト無しに付けられない）
- 任意のパスを開く口は作らない（開くのは設定ファイルに登録済みの id だけ）。静的ファイルは public/ の外へ出られないよう正規化して配る
- `.exe` / `.bat` などを登録するとクリックで実行されます（登録画面で注意を出します。設定ファイルを共有フォルダに置くなら、書き込める人に注意）

## 画面の操作

| 操作 | 動き |
|---|---|
| 円・名前を左クリック | 開く（成功・失敗はトーストで。見つからない・応答なしは理由付き） |
| 円・名前を右クリック | 編集（パス・名前・タグ・絵文字・メモ・削除） |
| 何もない所／タグを右クリック | 新規登録（タグで絞り込み中ならそのタグ、タグ上ならそのタグを最初から付ける） |
| 魔法陣の中の空き（中心含む）を左クリック | その魔法陣が画面に収まるよう寄る。外を左クリック or「⟲ 全体表示」で全体へ戻る |
| ドラッグして重ねて離す | 円→同じ先頭タグの円: 場所を交換 ／ タグ→タグ: 交換 ／ タグ→別の魔法陣の空き所: その魔法陣へ移す ／ 中心→別の中心: 左右の並びを交換。Esc か何もない所で離すと取り消し |
| キーを打つ | 検索欄へ入る。↑↓ で選択、Enter で開く、Esc で絞り込み解除 |
| 左ドラッグ／右ドラッグ／ホイール | 傾ける／移動／ズーム |

- 検索は名前・パス・タグ・メモをつないだ文字列への部分一致（空白区切りは AND、全角/半角・大小を区別しない）
- 凡例・分岐点のタグをクリックで絞り込み（複数選ぶと全部持つものだけ）。合わない円は暗くなり、カメラが合う円へ寄ります
- 待機中の動き: マウスがページの外へ出て 1 秒で動き出し、戻すと約 1 秒で元の表示へ（マウスが上・キー操作中・絞り込み中・ダイアログ中は動かない）
- 右上の 🍃 Light: three.js を読み込まず、文字の一覧と検索だけ（登録・編集・設定・開くは使える）。ブラウザの localStorage（`magic-launcher-lite`）に覚え、設定ファイルには書きません。WebGL が使えない環境でも同じ一覧で動きます

## テスト・確認用の環境変数

| 変数 | 意味 |
|---|---|
| `PORT` | 待ち受けポート（確認は 8791 など本番と別で） |
| `MAGIC_LAUNCHER_DATA` | settings.json・opener.exe・server.log の置き場（偽フォルダを指せば本番の設定を汚さない） |
| `MAGIC_LAUNCHER_DRY_RUN=1` | 実際には開かず、開くはずだったパスを返すだけ |

項目の登録を自動化するときも、ファイルを手で書き換えず、動いているサーバの `POST /api/item`（ヘッダ `X-Launcher: 1`）で入れて、`GET /api/state` で読み直して照合します。

魔法陣の描画部品（`public/magic.js`）は stable ポータルの `portal/magic.js` と同じもの（違いは目盛りを省く `lite` オプションと星の色指定だけ）。図柄は名前から決まる種で乱数を作り、同心円・弧・目盛り・幾何学記号を組み合わせたオリジナルです。
